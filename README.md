
 
This is an e-learning web application that contains interfaces for both admins and users. The admin can add or delete chapters, users, and other admins. Additionally, the admin can view orders and feedback.
🎓 Project Overview
This is a comprehensive PHP-based Online Learning Management System with a MySQL database backend. The platform supports multiple user roles and provides educational content management capabilities.

 System Architecture
Database: MySQL (projet database)
Connection: localhost, root user, no password
Tables:
user_info - Regular users/students
expert_info - Subject matter experts/instructors
admin_info - System administrators
subject - Course subjects (Title, Info, Dinfo)
chapter - Course chapters (Subject, Title, Info)
feedback - User feedback (Description, name, email)
Frontend Technologies:
HTML5/CSS3 with responsive design
Bootstrap for UI components
JavaScript libraries: jQuery, Owl Carousel, Slick Slider, etc.
Font Awesome icons
SweetAlert2 for notifications
Video background support
