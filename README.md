
 
This is an e-learning web application that contains interfaces for both admins and users. The admin can add or delete chapters, users, and other admins. Additionally, the admin can view orders and feedback.
is a full-stack e-learning web application developed by Daouthi Wassim. This project appears to be part of a Prodigy InfoTech internship program, as suggested by the naming convention (FS_02 likely indicates "Full Stack Project 02").
Key Features
For Administrators:

User Management: Add or delete users from the platform
Admin Management: Create or remove other administrators
Content Management: Add or delete educational chapters/courses
Order Management: View and manage course orders/enrollments
Feedback System: Monitor and review user feedback

For Users:

Access to educational content and chapters
Course enrollment capabilities
Feedback submission system
User-friendly learning interface
